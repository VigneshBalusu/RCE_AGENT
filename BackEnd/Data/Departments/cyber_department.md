# Department of CSE - Cyber Security (CS) - Ramachandra College of Engineering (RCEE)

## Overview of Cyber Security Department
* **Keywords:** Cyber Security, CSE CS, Cyber Security Profile, Cyber Seats, Cyber Intake, Ethical Hacking

## 1. Department Profile & Stats
* **Keywords:** Cyber Security Department, Established 2020, BTech Cyber Seats, CSE Cyber Security, Emerging Technology Branch
* **Overview:** Launched in 2020 to address the growing demand for security professionals, the CSE - Cyber Security (CS) specialization functions as an emerging technology branch under the CSE Department with an intake capacity of 60 seats for the B.Tech (UG) program.

## 2. Vision & Mission
* **Keywords:** Cyber Vision, Cyber Mission, CS Goals, Detect Cyber Threats, Prevent Cyber Attacks, Virtual Labs, Real World Defense, Cyber Ethics
* **Vision:** To carry out extensive awareness on the dangers of the internet and train students to detect, analyze, and prevent cyber threats to protect national cyber infrastructure.
* **Mission:** To build proficient skills for a Cyber Security career through Virtual Labs, develop strategies to counter cybercrime using real-time projects, and instill professional ethics regarding cyber laws and data privacy.

## 3. Leadership & Contact
* **Keywords:** Cyber HOD, Contact Cyber, CS Coordinator, Dr Shameena Begum
* **Details:** Functioning under the guidance of the CSE Head of Department, the Cyber Security program is coordinated by senior faculty member Dr. Shameena Begum (Contact: hod-cse-cs@rcee.ac.in). The office is located in the Main Block of the RCEE Campus.

## 4. Academic Focus & Curriculum
* **Keywords:** Cyber Syllabus, CS Subjects, Cyber Curriculum, Cryptography, Network Security, Ethical Hacking, Cyber Forensics, Blockchain Technology
* **Core Curriculum:** The specialized syllabus covers Cryptography (Encryption algorithms like AES/RSA, Digital Signatures), Network Security (Firewalls, VPNs, Intrusion Detection Systems), Ethical Hacking (Penetration testing, Vulnerability assessment), Cyber Forensics (Digital evidence recovery and analysis), and Blockchain Technology (Secure decentralized systems).

## 5. Laboratories & Infrastructure
* **Keywords:** Cyber Labs, Security Lab, Hacking Lab, Virtual Lab, Network Security Lab, Cryptography Lab, Unix Linux Lab
* **Facilities:** The department features a unique Virtual Cyber Security Laboratory simulating cyber-attacks for training. Key labs include the Virtual Cyber Security Lab (a sandboxed environment for Ethical Hacking), Network Security Lab (Cisco Packet Tracer, Wireshark), Cryptography Lab (Python/Java encryption), Unix/Linux Lab (Kali Linux command-line tools), and a Project Lab with high-performance systems for heavy security simulations.

## 6. Placements & Career Scope
* **Keywords:** Cyber Jobs, Cyber Placements, CS Salary, Security Roles, Security Analyst, Penetration Tester, Network Security Engineer
* **Placement Statistics:** As a niche branch, students are eligible for mainstream CSE software jobs plus specialized security roles. Recent batches have seen an average package of 3.5 LPA and a highest package of 7.0 LPA.
* **Top Recruiters & Roles:** Key recruiters include security and cloud divisions of TCS, Accenture and Wipro, as well as general tech giants like TCS, Infosys, Accenture, and HCL. Students are hired for roles such as Security Analyst (SOC Analyst), Network Security Engineer.
